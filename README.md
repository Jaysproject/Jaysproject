## How I work

1. **Scope it** — pin down the decision the analysis is actually for, before writing a query.
2. **Clean it** — the unglamorous part that decides everything: mixed date formats, duplicates, orphan keys.
3. **Model it** — star schema, surrogate keys, relationships that hold up.
4. **Measure it** — DAX written to be read by humans, then checked against the live model.
5. **Tell it** — the finding in plain language, the one chart that proves it, and what I'd do next.
